# Agent instructions

When someone is new to this repository, or wants to set it up, review it, demo it, or understand how part of it works, follow the guided tour in [.claude/skills/iac-tour/SKILL.md](.claude/skills/iac-tour/SKILL.md) and the reference files next to it. The same skill is available as `iac-tour` in Claude Code (`/iac-tour`) and Codex (`$iac-tour`, through `.agents/skills/`).

The rules that matter most:
- Ask before installing anything.
- Never ask for an API key in the chat, and never print `backend/.env`.
- Do not edit source files, commit, or push unless asked.
